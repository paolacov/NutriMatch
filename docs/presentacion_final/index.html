La decisión

Un dato faltante no se convierte en cero. Si la cobertura no alcanza, no se fuerza un puntaje. La misma entrada produce el mismo resultado.

Decisión metodológica

No todo problema de recomendación necesita aprendizaje supervisado

01 No existe un target observado.
02 No hay compras, clics, favoritos ni conversiones.
03 No es válido entrenar un recomendador supervisado con este catálogo.
04 Usar el puntaje, o las tres dimensiones, como etiqueta sería circular.
05 El sistema usa un motor determinista y auditable.

NutriMatch no utiliza aprendizaje supervisado porque el catálogo no contiene un target observado que permita entrenar y evaluar de manera científicamente válida un modelo de recomendación.

Para qué sirve

¿Qué aporta NutriMatch?

Persona

  • Reduce la comparación a un recorrido.
  • Muestra alternativas de la misma categoría.
  • Deja ver qué información sí existe.
  • Respeta el orden de prioridades declarado.

Ciencia de datos

  • Exploración que justifica decisiones.
  • Limpieza sin imputar lo que falta.
  • Variables comparables dentro de la categoría.
  • Evaluación y reproducibilidad del corte.

Producto

  • El análisis llega a una interfaz real.
  • Se puede recorrer una decisión de compra.
  • El resultado se puede explicar.
  • Se distingue lo real, lo faltante y lo simulado.
